\# DebugBuddy



DebugBuddy is a beginner-friendly Python debugging assistant, error explainer, and code analysis tool.



It helps answer:



\- What happened?

\- Why did it probably happen?

\- Where did it happen?

\- What should I check next?

\- What does this Python code do?

\- What potential problems are present?

\- How could those problems be fixed?



The core package is local and requires no API key.



\## Features



\### Debugging Assistant



Analyze Python programs and get structured information about:



\- Error type

\- Error message

\- Likely cause

\- File and line number

\- Source code context

\- Suggested debugging steps



\### Code Explainer



DebugBuddy can analyze Python source code using Python's AST and provide a structured explanation.



It can identify:



\- Imports

\- Functions

\- Classes

\- Variables

\- Basic variable types

\- Program flow

\- Potential issues

\- Suggested fixes



No external AI service is required.
